集計方法. package-lock.json（lockfileVersion 2）の packages オブジェクトから ""（ルートプロジェクト自身）を除く全 86 エントリを抽出し、各キーの末尾セグメント（最後の node_modules/ 以降）をパッケージ名として採用。名前が @ で始まるものをスコープ付きと判定し、@scope/name の @scope 部分でグルーピングした。ライセンスは lockfile 自体には収録されていないため、各パッケージの name と lockfile 記載の version を鍵に npm registry（registry.npmjs.org/<name>/<version>）へ個別に問い合わせ、応答の license フィールドをそのまま採用した（86/86 件で取得成功、欠損なし）。

留意点. ライセンス値は registry 上のメタデータをそのまま転記したものであり、実際のパッケージ内 LICENSE ファイルの内容とは突合していない。法務判断が必要な場合は個別に一次情報を確認すること。
